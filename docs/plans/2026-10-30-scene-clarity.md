# 牧云 · 场景精细度、文字与界面色彩优化

日期：2026-10-30。用户要求保留像素风，改善人物、动物细节、模糊中文与突兀的白色组件。本记录接续经营框架重构，单独记录本轮实施和验收。

## 原因与对应修改

| 角度 | 原因 | 已实施 |
|---|---|---|
| 素材精度 | 牧人仅 24×32、动物仅 32×32，服饰、毛发、角蹄和明暗层次有限 | 新四方向四帧透明图集：牧人 48×64、牦牛与藏羊 64×64；整套共享比例、脚底归一化，保持原世界显示尺寸 |
| 渲染链路 | 8px Phaser 中文先进入 480×270 画布，再整体放大，字形细节不足 | 内部画布提高到 960×540，镜头 zoom=2；世界视野保持 480×270。地点中文独立为 14px DOM 标签，紧凑布局 13px |
| 色彩关系 | 近白 HUD 与草场亮度差大，像独立网页浮在游戏上 | 常驻 HUD 固定深林绿，晨光菜单改草木灰绿，保留暮色菜单；草金色突出主要行动 |
| 动态表现 | 动物簇团重叠，始终朝下并持续漂移 | 均匀分布、随机初始朝向、按位移方向短走停留，限制漂移范围，深度随 y 更新 |
| 场景层次 | 原暗角最高黑色 alpha 0.5，深色动物与草地分离弱 | 暗角减至 0.18；校正高分辨率下的季节罩色、暗角与雪花位置 |
| 交互与适配 | 场景标签容易与 HUD 或弹窗争夺注意力 | 标签投影使用实际画布边界与镜头视野，避开 HUD，弹窗时隐藏；窄屏隐藏标签的溢出已裁切 |

本项目使用 2D 像素精灵；本轮细化的是精灵美术与渲染，未引入 3D 模型。生成入口、模型、源图和授权说明见 `ASSETS.md`。
