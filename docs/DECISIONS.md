# DECISIONS · 方案修正与执行基线

## 1. 采用 Phaser 2D，而不是 Three.js 3D

仓库里有三份不同阶段的方案，技术路线和周期互相冲突：

- `docs/plans/2026-10-27-pixel-campus-full-execution-plan.md`：Phaser 3 + 2D 俯视 3/4，15 周（**执行基线**）。
- `docs/plans/2026-10-27-pixel-campus-3d-alternative.md`：Blender + Three.js + 等距 3D，8 周（归档备选）。
- `docs/plans/archive/2026-10-27-pixel-campus-10week-draft.md`：Phaser 2D，10 周（早期草稿，已被 15 周方案取代）。

**执行以最新的 15 周 Phaser 2D 方案为准**；3D 方案和 10 周草稿都归档为备选/历史。原因：

- 1 人 + AI 辅助，纯文本工程更可控；
- 首屏包体小，移动端启动快；
- 2D 瓦片地图更容易用脚本生成和批量修改；
- 学校 3D 地图只作为布局参考，不直接复用模型/贴图。

## 2. 地图从“通用占位”改为“青海大学相对布局”

用户提供了 https://gis.qhu.edu.cn/#/ 。我抓取了公开点位数据（北门、西门、东门、南门、图书馆、田径场、学院楼等），换算到 160×120 格。

- 只参考名称、相对坐标、道路拓扑；
- 不提取 3D 模型、贴图、倾斜摄影；
- 地标位置有手工调整，保证可走通；
- 详见 `docs/QHU_MAP_REFERENCE.md`。

## 3. 美术：程序化生成占位素材

方案原本假设 Kenney/LimeZu 素材包，但：

- 没有现成素材包可下载/核对授权；
- 先要保证可玩闭环，不被素材阻塞。

因此 v0.1 用 `tools/gen-assets.mjs` 生成整套原创 CC0 占位素材。后续可按 `ASSETS.md` 替换。**不用于瓦片级 AI 生成图**，坚持程序化/手绘像素。

## 4. 音频：WebAudio 合成占位

没有 CC0 音频包，先用振荡器合成 BGM/音效，规避版权与加载体积。后续替换时登记授权。

## 5. UI：HTML/CSS 叠加层，而不是 Phaser UIScene

方案要求 HTML/CSS UI；实际用 `UIManager` + DOM 直接实现，没有单独的 Phaser `UIScene`。这样中文排版、滚动、移动端适配更容易。场景流仍是 Boot → Preload → Title → Campus → 小游戏/弹窗。

## 6. 存档版本 v3

地图从通用占位换成学校布局，随后又扩展为全校区，玩家坐标不再兼容。`SAVE_VERSION = 3`：

- v0/v1/v2 存档保留进度、猫、成就、设置；
- 玩家位置重置到北门新生点；
- 旧档迁移有单元测试。

## 7. 小游戏宿主

方案里写“每个小游戏是独立 Scene + MiniGame.start 契约”。实际：

- 宠物对战：`PetBattleUI` 控制 DOM 弹窗，`battle.ts` 纯逻辑，返回 `Promise<BattleResult>`；
- 躲猫猫：`HideSeekGame` 控制状态与 HUD，CampusScene 负责藏点标记和触发器。

行为契约一致（开始 → 暂停世界 → 结算 → 返回奖励），但没有额外 Phaser Scene。原因：小游戏 UI 全是 DOM，单独 Scene 只会增加空壳；等需要复杂 Phaser 动画时再拆 Scene。

## 8. 范围修正

- 15 周方案里的“首屏 < 5MB”按 gzip 计算，当前远低于预算。
- 首版不做真实室内、联机、账号、云存档；与方案一致。
- 增设“西田径场”作为主操场，东田径场作为氛围区域；宠物对战/躲猫猫/看台放在西田径场。
- 2026-10-27 用户确认：青海大学没有统一的“主楼”，教学楼按院系分布。已删除“主楼/主教学楼”概念，改为睿智楼、尚真楼、融馨楼、逸夫楼、圣汇楼等多个上课点；地图从核心环线扩展为全校区 160×120。

## 9. 宠物对战新增 defense 字段

原方案的宠物数据只有 HP / 攻击 / 速度 / 技能，但伤害公式里写“− 防御修正”。为了不引入一个没有数据来源的抽象系数，`pets.json` 增加 `defense`（3–6），伤害改为：

`max(1, round(skill.power × 属性倍率 × 0.85~1.0 − defense × 0.6))`

这样数值可解释、可测试，后续平衡只改 JSON。
