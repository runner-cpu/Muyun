# 青海大学地图参考

本项目的校园布局参考青海大学公开的「可视化位置服务平台」：

- https://gis.qhu.edu.cn/#/
- 平台版权信息：版权所有 青海大学 · 版本 v2.0 · 俯视角 45°

只参考**建筑相对位置、名称和道路拓扑**，不提取、不复用平台里的 3D 模型、贴图或倾斜摄影数据。游戏内全部像素素材由本项目生成。

## 建筑 footprint

平台的前端还加载了公开的建筑 footprint GeoJSON：

- 接口：`https://gis.qhu.edu.cn/cmgis-server/map/v1/mapdata/threeDimensionSource/2`
- 本地快照：`maps/qhu-buildings.geojson`（128 个 feature，只用于读取建筑轮廓、层数和高度）
- 生成结果：完整 128 个 footprint 保存到 `maps/qhu-buildings.geojson`；可玩地图使用其中 19 个核心建筑轮廓，缩放后做 2.5D 精灵
- 没有使用平台的 3D 模型、贴图或倾斜摄影数据

游戏内这些轮廓会缩放到当前核心校园区块的 bbox 内，因此是“真实轮廓 + 游戏化比例”，不是测绘级 GIS 坐标。

## 映射规则

- 校园经度范围约 `101.7418 – 101.7532`，纬度范围约 `36.7226 – 36.7338`。
- 可玩地图 `160 × 120` 格，每格 16px，北向上。
- 地标位置换算后做了少量手工调整，保证道路连通和行走舒适度；不是测绘级坐标。
- 需要更精确的复刻时，优先补充：各建筑入口位置、层数、屋顶颜色、校门立面照片。
