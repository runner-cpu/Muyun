# 牧云：38 个角度的综合检查与改进

日期：2026-11-01。基础提交：`b813a88`。定位：高原草畜平衡的像素经营、决策训练与可复现策略实验。

本次结合源码、已有模型深审、自动回归、真实 Chromium 交互与截图检查。历史问题明确注明来源；不把旧实验当成新实验，不把浏览器模拟尺寸当成移动真机，不把功能完成当成学习效果证据。模拟仍是 `decision-v2`，规划器仍是 `beam-profile-v2`，评价仍是 `decision-assessment-v1`，存档仍是 schema v2。

## 核心判断

项目已经具备能玩的闭环与可核验的模型内实验。当前最需要提高的是两层质量：第一层是操作连续性、异常恢复与阅读负担，直接影响玩家能否顺利完成一次决策；第二层是模型口径、长短期目标和证据强度，决定比赛中能否解释作品的价值及局限。

这次实际修复第一层的已确认问题，增加本周真实行动回顾，并将试算放入可取消的后台 Worker。第二层涉及模拟规则变更及真人、专业和赛事证据，需要独立版本与实证工作，下面逐项给出验收办法。

## 本次已实施的改动清单

- 真实本周行动、未利用草区与概览结算入口，默认收纳，不新增常驻 HUD。
- 集市保留购草输入/种类/页码；策略保留同状态实验和偏好，真实状态变化即失效。
- 周试算、完局对照转至可取消 Worker；失败、超时、离开和迟到结果有处理。
- 损坏存档不再静默变新局；数据结构校验、错槽拒绝、已有存档重开确认及错误提示。
- 必需素材加载失败时留在恢复页，提供重新加载入口；保留原本地存档。
- 键盘焦点隔离、短屏资源换行/限高、固定面板标题、矮屏错误提示及废弃 CSS 清理。

## 下一轮的优先级和完成标准

1. **模型一致性先于新增内容。** 以 23/24/27/28 的最小反例建立守恒、成本和时间约束；专家核对后单独升模拟版本，明确迁移策略并保留旧报告。
2. **整局决策能力先于更多“推荐”。** 对固定开局留存、季节使命和多周压力做约束/规划对照；至少给出当前默认挑战条件的可重放达标轨迹，若找不到则继续如实报告。
3. **专业和真人证据先于效果宣传。** 组织目标受众任务试玩，观察从风险识别到解释结果的完整过程；记录失败原因、耗时和误解。开展前后知识评估时预先写清问题、样本和分析口径。
4. **设备和答辩证据补齐。** iOS/Android 真机、辅助技术及弱网测量；录制当前版本真实四周经营、实验导出与复算。正式赛事材料按目标届次重新核对。

本次完成的是体验与可靠性的具体修复；以上未完成的模型、科学、资格和真实使用验证保持可见，不写作已解决。
