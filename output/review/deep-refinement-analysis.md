# 牧云：26 个角度的深化分析与改进记录

日期：2026-10-30。定位：保留像素高原牧场，以草畜平衡为主题，提供决策训练与可复现策略实验。本报告对应本轮实际修改；前轮已完成的像素人物、动物、场景和高原手记作为现有基础，不重复算作本轮新增成果。

当前模拟 `decision-v2`，评价 `decision-assessment-v1`，规划器 `beam-profile-v2`，存档封装 schema v2。模拟、评价、规划器与文件格式分别编号。没有通过临时修改价格、权重、事件或繁殖规则美化本轮成绩。

## 核心判断

当前最需要改进的是不同时间尺度之间的连接：玩家看到的是本周资源，搜索优化的是本周结果，季末使命要求跨周安排，最高成果还要求相对真实起点保留资产、存栏与健康。只增加操作和装饰，不能解决这四者的不一致。

本轮把可确认的工程缺陷、信息缺失和候选盲区落实为代码；会改变模拟含义的问题则保留具体复现和后续验收要求。现有实验说明搜索能降低当前脚本下的失败，但没有证明它已能完成整体任务，也没有证明真实牧场收益或学习效果。

## 主要改动的使用方式

打开“本周概览”“集市”或“本周策略试算”，进入“三周储备账”。先看仅凭当前库存会从哪次结算缺草，再看假设逐周补足需要的草费和固定费，最后核对距季末/局末次数，以及真实起点对应的保留存栏底线。两条预算路径独立，假设购买不会把仅靠现有库存的缺口抹掉。

该账最多算当前到未来三次结算，且不越过第13周；固定当前存活畜群、体重、人员和设备，已知当周暴雪只作用于当前价格。未来不安排放牧、收割、买卖、繁殖、生长或事件，假设整公斤补草也不意味着已付款或有足够AP。已结束的局不补造未来周次。

策略参考仍由玩家亲自执行。明细新增与整局保留底线的距离，局末表把流程完成、最高成果与保留比例拆开。清档和输入修复则保障玩家查看、执行与恢复这一流程时不会被另一槽覆盖或失效按钮打断。

额外4032次有界参数探索，在三个公开seed、两个场景内找到非默认越冬seed `20261015` 的可复算达标轨迹：经营44.35、生态65.63、健康100，保留45/78羊单位（57.69%）。这是事后筛选且含等价参数的可行性证据，未进入正式基准，不能推出成功率。默认越冬seed和三个全年起点在该有限规则族内未找到达标，也不能证明目标不可达。

## 下一阶段优先级与验收门槛

1. **统一饲喂、经济与人手的规则含义。** 定义实际摄入与扣草、库存残值与现金收益、家庭劳动与雇工成本，再以独立模拟版本验证。验收至少包含“同样实际摄入不因闲置库存获得额外体况”“采购不被误报为利润”“人员损失有与文案一致的成本”；保留旧版回放路径与基准，不悄改历史。
2. **让长期任务进入规划。** 先固定整局原始保留底线，补季节使命与终端储备处理，再研究有限多周规划。新增轮休/储备/维护启发式，记录候选覆盖与等价状态去重，同预算做消融；先冻结方法与seed再跑。必须同时报告失败、达标、三维分数、存栏、现金、库存与耗时，不能只看综合分。
3. **建立跨周经营后果。** 繁殖窗口、合作/口碑与事件持续影响分别设计最小可解释机制，避免添加没有收益链的旗标。检查是否仍有明显支配选项；不要靠结局奖励抬分掩盖经营问题。
4. **补真人、专业与交付证据。** 先用新玩家完成“观察—比较—执行—解释”任务，记录误解与卡点；专业核对关键机制；再做iOS/Android真机、低端设备和首屏测量、实际演示排练与素材/贡献打包。研究未做之前保持“设计目标”措辞。

本轮已消除新增范围内复核到的P1/P2，并不表示整个模拟、算法或比赛材料已无缺口。仍有一个非阻塞体验项：从储备账返回集市或策略时，会重建筛选/输入或试算结果；后续可保留局部面板状态。
