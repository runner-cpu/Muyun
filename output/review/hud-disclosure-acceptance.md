# 牧云：界面收纳与简易引导验收

日期：2026-10-30

## 原因与处理

- 场景同时常驻资源、周提示、四项导航、结算和键位说明，压缩牧场视野。改为状态、本周安排、经营工具、周结算、帮助五个原生收纳栏，首次全部收起，一次只展开一栏。
- 关闭面板后若焦点回到已隐藏的按钮，键盘操作会失去位置。打开经营面板前收起所属栏，并先将焦点放回可见标题；Space 保留 summary 的原生展开行为。
- 长说明与当前风险同级展示，增加首次阅读负担。概览保留风险、核心需草/库存/费用/现金与当前使命；计算细节、储备/策略/手记及四季记录按需展开。科技保留价格、维护费、行动点和购买操作，记录明细收纳，并在有效操作后保留展开状态。
- 初次进入缺少操作顺序。加入三步简易引导：看本周、安排经营、结算复盘。支持前后切换、跳过和关闭，可从帮助或玩法说明重看，不执行经营动作。

## 实现边界

HUD 布局与引导已看状态独立于两个游戏存档。浏览器存储不可用时仍保留会话偏好。缺草、现金将耗尽或患病风险仍显示在收起的本周安排摘要。场景标签避让展开后的真实 HUD 边界，隐藏栏不占遮挡区域。

本轮未修改模拟规则、评分、权重、随机过程或行动代价。首次引导让位于恢复中的未决事件和其他阻挡面板。

## 验证

- Vitest：42 个文件、310 项测试全部通过，包含新增 HUD 互斥/存储异常/焦点/解绑重绑、summary 的 Space 键行为、引导生命周期与面板收纳回归。
- `npm run build` 通过，含 TypeScript 检查。Vite 提示引导同时被静态与动态引用，因此不会拆成独立 chunk；不影响功能与构建产物。
- 独立只读审查无 P1/P2 问题；已修复隐藏的本周安排栏仍被场景标签计为遮挡的问题。
- 浏览器验收使用独立的 `127.0.0.1:5187` 测试存档，不操作用户的 `localhost` 存档。
- 1280×720：五栏开关与互斥、Space 收放、经营与结算确认后的焦点回标题、三步引导衔接概览、科技操作重渲染后保持展开通过。
- 844×390：摇杆与经营入口分离，资源与帮助入口不重叠，帮助/安排明细可滚动；暮色主题引导可读，概览储备与策略入口可展开访问。
- 刷新后恢复帮助栏展开状态，不重复弹出已看引导；手动重看、跳过正常。根页面无横向溢出。

本轮为浏览器视口模拟验收，尚不等同于移动设备真机验收。线上发布结果以对应 GitHub Actions 和实际 Pages 页面为准。
