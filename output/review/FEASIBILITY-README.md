# 有界可行性诊断

2026-10-30。目的：检查现有两个参考策略均未达标，是否意味着当前目标一定不可达。该诊断不修改业务规则、正式基线或默认挑战 seed，也不是新的统计基准。

## 预算与共享规则

- 仅使用公开 seed `20261001 / 20261015 / 20261030`，每个 seed 分别运行全年和越冬两个现有场景。
- 第一阶段 480 组参数×6 起点＝2880 次；第二阶段 192 组参数×6 起点＝1152 次，共 4032 次诊断。包含重复等价参数，不能视为 4032 个独立样本。
- 单阶段脚本内设置 120 秒执行保护；实际第一阶段约 790 ms，第二阶段约 356 ms，未触发时间保护，随后停止扫描。
- 每次行动、事件和周结算均调用正式 `applyAction / resolveEvent / endWeek`，遵守真实 AP、现金、设备维护及离群记录。没有修改 `decision-v2` 数值或读取未来随机结果。
- 事件统一采用与现有自动策略相同的“首个合法且可支付选项”。规则只看当前状态：按预定比例减载、治疗、可选免疫、轮牧、必要补草/卖畜；全年有空余 AP 时也尝试配种。
- 第二阶段仅增加每周开始时尝试一次符合退化上限的轮牧，以保留原有库存；不再仅等干草将耗尽时才放牧。
- 参数和展示轨迹是观察结果后筛选的探索性证据，不能用来主张正式成功率或泛化效果。特别是达标 seed `20261015` **不是默认越冬 seed `20261030`**。

4032 次中，只有第二阶段 seed `20261015` 的18个参数配置达标；这些存在等价配置，不能称为18条独立成功样本。其余结果和全部失败都在 JSON 中保留。默认越冬 seed `20261030` 和三条全年起点在本次有限规则族内均未找到达标；这不证明它们不可达。
