# 标题与进入牧场

- 范围：`TitleScene.ts` 与标题高原图；访客模式为 **Experience**。
- 玩家与任务：第一次打开或回来继续的中文玩家，应先认出《牧云》的像素高原世界，再开始新局或继续本地存档。
- 内容与证据：真实游戏名称、十三周四季的玩法描述、真实存档可用状态；玩法说明与设置是次要入口。
- 约束：保留像素身份、既有新局和存档流程；手机竖屏也能读取标题与进入菜单，不为文案增加未经实现的玩法承诺。
- 已选方向：让高原景象占据画面，左侧以品牌名称、两行玩法和主要行动形成稳定阅读顺序。绿色遮罩为文字提供可读区域，不覆盖整幅图。
- 记忆点：高原牧场与像素“牧云”标题共同出现，“山野有时，放牧有度。”承接经营节奏。
- 审查记录：上一轮标题画面的独立视觉审查为 `ship`，无重大开放项。本轮牧场角色与牲畜提高细节密度，缩小与标题插画的差距；标题场景同步 2× 内部渲染，已检查标题与继续存档进入，设置存档测试通过。本轮场景独立审查为 `ship`，见 `docs/plans/2026-10-30-scene-clarity.md`。
- 已验证：标题页设置只更新已有存档的 settings，保留 run 与 player；音量跨刷新保留，继续游戏保持原局。无存档时调整设置不创建默认局。
- 待确认：低性能真机表现。已执行的多视口浏览器检查见实施计划。
- 决策训练扩展：明确区分十三周完整经营、四周越冬挑战及各自继续入口；挑战进入前解释给定种子、存栏、储备和已安装设备及持续费用。两种模式独立存档，完局可回到主菜单并按相同条件重试。
- 版本边界：当前模拟为 `decision-v2`，存档封装仍为 schema v2。旧模拟进度保留，从续玩状态重建当前规则的记录和评价基线，当前周已知小区利用保留；旧轨迹不伪装成v2完整经历。已结束而没有可玩起点的旧档只提供快照来源，不提供虚构对照。
