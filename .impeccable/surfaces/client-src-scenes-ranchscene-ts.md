# 牧场经营与周决策

- 范围：牧场场景、HUD、经营导航和经营弹窗；访客模式为 **Operate**。
- 玩家与任务：正在游玩的中文玩家，需要看懂本周资源、饲草缺口和剩余行动，安排照料、放牧与交易，再推进到下一周。
- 内容与证据：HUD、畜群和集市列表、草场状态、科技能力、周回顾均读取真实模拟状态；费用、收益、禁用原因与最新日志解释行动结果。
- 约束：模拟规则通过纯 TypeScript 内核共享；保留畜群、草场、集市、科技四个名称及 `1-4` 快捷键。科技能力按当前实现披露。个体列表必须完整可达，强制事件不能被关闭跳过。
- 已选方向：像素牧场保持主画面。顶部集中资源，底部稳定经营入口和周推进；具体决定进入可读的 DOM 面板。先摘要，再对象，再代价和结果，经营动作组左对齐。
- 关键体验：从饲草缺口进入草场或集市，看到行动结果原位刷新；结束本周先确认，再阅读真实经营回顾并处理事件。
- 响应行为：桌面保留周提示；紧凑横屏保留可点击的缺草/患病/行动状态摘要，进入概览处理。弹窗统一纵向滚动，表格只处理横向溢出；手机牧场竖屏显示横屏提示。
- 本轮细化：内部画布 960×540、镜头 2×，世界逻辑与视野保持 480×270；牧人、牦牛与藏羊使用细化四方向图集，保持世界显示尺寸与碰撞范围。牲畜均匀分布、按方向短距离走停，暗角减至 0.18。
- 本轮文字与色彩：地点使用 14px DOM 标签（紧凑 13px），按镜头与画布边界投影，避让 HUD 并在弹窗时隐藏。常驻工具固定深绿，晨光菜单改草木灰绿，提高辅助字号。
- 审查记录：前轮精灵、文字和配色独立审查为 `ship`，历史桌面与横屏、地点点击、遮挡和主题证据见 `docs/plans/2026-10-30-scene-clarity.md`。当前 `decision-v2` 已补紧凑风险摘要，最新规则与浏览器验收按版本另记，不覆盖旧记录。
- 待确认：真实设备的触屏、性能表现；已执行的周流程、多视口和键盘检查见实施计划。
- 决策训练扩展：概览优先当前风险、经营入口、饲草与费用，再给使命和策略入口。草场先总草量/休牧区/行动摘要与操作，监测对照按需展开。集市自定义购草量可执行参考序列；事件列出即时变化。结算显示三维成果、周记录、完局对照与 JSON；不将游戏参数说成行业标准或实证教学效果。
- v2规则：每区每周只能放牧或收割一次，两种利用都中断休牧，当周不恢复；仅未使用区可自然恢复，连续休牧达到条件后退化最多下降1个百分点、最低为0。defer只在全部常规事件选项不可执行时出现，承担有界BCS −0.2与退化+0.02。旧模拟记录不混入v2，从当前续玩状态重建基线。
- 场景反馈：实际kg/ha驱动草密度、退化驱动裸土、割草呈茬行，标签与面板共用利用状态。每种活体按ceil(45%)、最多18头抽样并绑定真实ID，红菱/黄三角/青色颈带配合个体档案提示健康/体况/项圈。精灵点击和畜群耳标进入同一真实档案；样本位置为展示槽位，不模拟真实分区或路线。完整存栏以HUD与全部列表为准。
